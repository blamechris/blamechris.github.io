# blamechris.github.io

Personal portfolio site, served at [www.blamechris.com](https://www.blamechris.com) via GitHub Pages (branch: `gh-pages`).

## ARchery

Play [ARchery](https://www.blamechris.com/archery/) at `/archery/`.

To refresh the game, build the approved game release with `--base=/archery/` into a separate output directory. Copy only the compiled `index.html` and `assets/index-*.js` / `assets/index-*.css` into `archery/`, replacing the previous release files. Include the Three.js MIT license in `archery/THIRD_PARTY_NOTICES.txt`. Never copy source files, source maps, configuration, package files, repository metadata, or private release information. Verify the game loads and plays at `/archery/` before publishing.
